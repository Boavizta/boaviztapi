# SDKs

Client libraries that make BoaviztAPI easier to call from other languages.

They are maintained by the community, not by Boavizta. Report bugs to their own repositories.

| Language | Library | Maintainer | Status |
|----------|---------|------------|--------|
| PHP | [boaviztapi-php](https://github.com/DavidJLN/boavizta-api-php) | [@DavidJLN](https://github.com/DavidJLN) | Community, unofficial |

## Add your SDK

Open a pull request that adds a row to the table above and to the [SDKs page of the documentation](docs/docs/sdks.md).
